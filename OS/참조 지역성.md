CPU가 메모리에 접근할 때 특정 위치나 그 주변을 반복적으로 참조하는 경향을 의미하며, 캐시 메모리의 적중률을 높여 CPU의 메모리 접근 횟수를 줄이는 데 활용됩니다.

## 시간 지역성과 공간 지역성

- **시간 지역성(Temporal Locality)**: 최근에 접근한 메모리 공간에 다시 접근하려는 경향. 지역 변수에 값을 저장한 뒤 다시 참조하는 경우가 대표적입니다.
- **공간 지역성(Spatial Locality)**: 접근한 메모리 공간 근처에 접근하려는 경향. 배열을 순차적으로 순회하며 접근하는 경우가 대표적입니다.

## 캐시와의 관계

CPU 캐시는 공간 지역성 원리에 근거해 물리적으로 인접한 데이터를 미리 캐싱합니다. 참조 지역성이 높을수록 캐시 적중률이 올라가고, CPU가 상대적으로 느린 메인 메모리에 직접 접근하는 횟수가 줄어 성능이 향상됩니다.

## 사용 예 - 2차원 배열 순회 최적화

자바의 2차원 배열은 내부적으로 1차원 배열(`int[]`)에 대한 참조 배열이며, 각 행(`array[i]`)은 독립된 객체로 메모리상 연속적 배치가 보장되지 않습니다. 열을 먼저 순회하면 물리적으로 멀리 떨어진 데이터를 반복 접근해 캐시 적중률이 떨어집니다.

```java
// 캐시 적중률이 낮은 방식 - 열 우선 순회
for (int j = 0; j < size; j++) {
    for (int i = 0; i < size; i++) {
        array[i][j]++;
    }
}

// 캐시 적중률이 높은 방식 - 행 우선 순회
for (int i = 0; i < size; i++) {
    for (int j = 0; j < size; j++) {
        array[i][j]++;
    }
}
```

행 우선 순회는 공간 지역성을 활용해 인접한 메모리 주소를 순차적으로 접근하므로, 열 우선 순회보다 캐시 적중률이 높아 실행 속도가 크게 향상됩니다.

## 핵심 정리

참조 지역성은 시간 지역성과 공간 지역성으로 구성되며, 캐시 메모리 설계와 배열 순회 순서 같은 프로그램 성능 최적화의 핵심 원리로 활용됩니다.
