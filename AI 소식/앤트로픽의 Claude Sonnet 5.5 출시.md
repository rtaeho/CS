앤트로픽이 "Claude 5.5 패밀리의 두 번째 모델"이라고 소개한 Claude Sonnet 5.5를 출시하며, 에이전트가 만든 코드 변경이 실제로 머지될지 측정하는 새 지표 FrontierCode를 함께 공개했다.
기준 시점: 2026-09-28

## 무슨 일인가

앤트로픽 공식 발표에 따르면 2026년 9월 28일 Claude Sonnet 5.5(모델 ID `claude-sonnet-5-5`)를 출시했다. Claude Opus 5.5보다 빠르고 저렴한 보완 모델이자 Claude Sonnet 5의 업그레이드로 소개한다.

가격은 Sonnet 5와 동일하게 100만 토큰당 입력 $2, 출력 $10이지만, 캐시 읽기는 100만 토큰당 $0.10으로 Sonnet 5의 절반이라고 밝혔다. 출력 속도는 Sonnet 5보다 30% 넘게 빠르고, 작업당 비용은 최대 30% 낮아졌다고 설명한다.

벤치마크 결과(Sonnet 5.5 / Sonnet 5 순)도 공개했다: Terminal-Bench 4.0 70.6% / 10.3%, CursorBench 4.0 55.5% / 34.1%, Humanity's Last Exam(툴 사용) 64.5% / 54.9%, OSWorld 2.1(부분) 80.1% / 57.0%, Chartography(툴 없음) 61.6% / 15.6%.

새 지표인 **FrontierCode**는 "에이전트의 코드 변경이 사람 손 없이 머지될 수 있는지를 측정"한다고 밝혔고, 이 지표에서 "Sonnet 5.5는 작업당 비용의 약 5분의 1로 GPT-6 Sol의 최고 점수와 맞먹는다"고 설명했다. 다만 같은 지표에서 "Sonnet 5.5는 Max effort보다 Xhigh effort에서 더 낮은 점수를 받았다"는 점도 함께 밝혔다.

안전 쪽에서는 **preserved thinking**(Claude의 사고 과정을 생성한 계정에서 분리할 수 없게 하는 조치)을 확장했다고 밝혔다. 목적은 "안전장치 없이 고성능 모델을 만들 수 있게 하는" 증류를 막는 것이라고 설명하며, 계정을 바꾸면(Claude Code에서 세션 중 계정을 전환하는 경우 포함) 영향이 있다고 안내했다. 추론을 끄고 Sonnet을 쓰던 사용자는 Sonnet 5.5로 옮기기 전에 새로 생긴 `between_tools` 설정으로 바꿔야 한다고도 밝혔다. 또한 Sonnet 계열 모델 중 처음으로 사이버 안전장치와 폴백을 갖추고 출시됐다고 설명했다.

Effort 설정(Low/Medium/High/Xhigh/Max)은 "낮은 설정에서는 더 빨리 답하고 토큰을 적게 쓰며, 높은 설정에서는 더 오래 추론하고 결과를 더 꼼꼼히 검토한다"고 설명한다. 기본값은 Claude Code·앤트로픽 앱에서는 Medium, Claude Platform에서는 High라고 밝혔다.

## 왜 중요한가

FrontierCode는 "테스트를 통과하는가"가 아니라 "사람 손 없이 머지될 수 있는가"를 재는 지표라, 실제 개발 현장에서 느끼는 유용성에 더 가까운 측정으로 보인다. 같은 지표에서 Max effort가 Xhigh보다 낮은 점수를 받았다는 공개는, 추론 강도를 높인다고 항상 결과가 좋아지지는 않는다는 걸 앤트로픽이 직접 수치로 보여준 사례라는 점에서 눈에 띈다.

preserved thinking을 Sonnet 계열까지 확장한 점도 의미가 있다. 증류 방어가 더 이상 최상위 모델만의 조치가 아니라, 모델 세대 전반에 적용되는 기본 정책으로 자리잡아가는 흐름을 보여준다.

## 짚고 갈 개념

- FrontierCode — 에이전트가 만든 코드 변경이 사람 손을 거치지 않고 실제로 머지될 수 있는지를 재는 평가 지표
- Effort 설정 — 모델을 호출할 때마다 추론 강도(Low~Max)를 선택해 비용과 성능을 맞바꾸는 옵션

## 내 생각

Max effort가 Xhigh보다 낮은 점수를 받았다는 사실은, effort를 작업 종류별로 실측해서 고르지 않으면 오히려 손해를 볼 수 있다는 뜻으로 보인다. "더 오래 생각하면 더 잘한다"는 직관이 적어도 FrontierCode 같은 실전형 지표에서는 깨질 수 있다는 걸 보여주는 사례로 느껴진다. preserved thinking을 Sonnet까지 내려 보낸 것도, 안전장치 비용을 플래그십 모델만 지는 구조에서 모든 모델이 나눠지는 구조로 바뀌어가는 신호로 보인다.
