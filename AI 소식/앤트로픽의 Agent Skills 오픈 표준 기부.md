앤트로픽이 에이전트에 절차적 지식을 넣는 개방형 표준 Agent Skills를 리눅스 파운데이션 산하 Agentic AI Foundation(AAIF)에 기부했다고 밝혔다.
기준 시점: 2026-10-22

## 무슨 일인가

앤트로픽 뉴스룸에 따르면, 2026년 10월 22일 Agent Skills 표준과 함께 Agent Skills라는 이름·로고, 깃허브 조직, agentskills.io 도메인을 AAIF에 넘긴다고 밝혔다. 앤트로픽은 "Agent Skills를 계속 열려 있고 커뮤니티 주도적이며 특정 벤더에 종속되지 않게 유지하는 데 전념한다"고 밝혔다.

Agent Skills는 에이전트에게 특정 작업이나 도메인을 가르치는 표준이다. 스킬 하나는 `SKILL.md` 파일과, 필요하면 스크립트·참고 자료를 담은 폴더 형태다. 앤트로픽은 Claude Code를 만들면서 이 개념을 다졌다고 밝혔다. Claude Code는 일반적인 지식 작업은 잘 처리했지만 실제 업무에 필요한 절차적 지식은 자주 빠져 있었다는 것이다. 2025년 10월 출시 이후 개발자들이 깃허브에 수천 개의 스킬을 올리고 Codex·Cursor·OpenCode용 로더까지 직접 만들자, 앤트로픽은 2025년 12월 Agent Skills를 어떤 에이전트도 쓸 수 있는 개방형 표준으로 공개했다고 한다.

뉴스룸은 현재까지 70개 넘는 에이전트 플랫폼(ChatGPT, Cursor, GitHub Copilot, VS Code 포함)이 Agent Skills를 통합했고, 스킬 100만 개가 게시됐으며, 설치 건수는 약 2억 8천만 건에 이른다고 밝혔다.

AAIF는 리눅스 파운데이션 산하 재단으로, 앤트로픽이 Block·OpenAI와 함께 전년에 공동 설립했으며 이미 MCP(Model Context Protocol)를 이 재단에 기부한 바 있다고 한다. 앞으로는 앤트로픽·구글·OpenAI 등 여러 회사의 엔지니어들이 개인 자격으로 표준을 유지보수하며, David Soria Parra와 Mahesh Murag가 리드 메인테이너를 맡는다. AAIF 가입은 필수가 아니며, 가입하지 않아도 표준을 쓰거나 기여할 수 있다고 한다. 앞으로의 로드맵으로는 버전 관리된 릴리스, 공식 제안 절차, 스킬 작성자·설치자를 위한 보안 가이드를 제시했다.

## 왜 중요한가

Agent Skills가 Claude Code 전용 기능에서 70개 넘는 플랫폼이 통합하는 개방형 표준으로 넘어갔다는 점, 그리고 MCP에 이어 두 번째로 벤더 중립 재단에 넘겨졌다는 점이 눈에 띈다. 에이전트를 실제로 만들 때 "툴을 어떻게 호출시킬 것인가"(MCP, 함수 호출)뿐 아니라 "에이전트에게 특정 작업의 절차적 지식을 어떻게 넣어줄 것인가"도 별도의 표준화 대상이 되고 있다는 뜻이고, 표준이 한 회사 소유가 아니라 재단 소유가 되면 그 표준에 기대어 도구를 만드는 쪽의 장기적 리스크도 낮아진다.

## 짚고 갈 개념

- Agent Skills — `SKILL.md` 폴더 단위로 에이전트에 특정 작업의 절차적 지식을 넣는 개방형 표준
- MCP — 모델에 외부 컨텍스트·툴을 붙이는 프로토콜. AAIF가 먼저 기부받아 관리하던 표준으로, Agent Skills가 그 뒤를 따랐다

## 내 생각

이번 기부에서 흥미로운 부분은 "표준을 누가 갖고 있는가"의 변화 속도로 보인다. Agent Skills는 2025년 10월 등장해 1년 만에 개방 표준 공개, 70개 플랫폼 통합, 재단 기부까지 이어졌는데, 이 정도 속도라면 당분간 비슷한 패턴(한 회사가 내부용으로 만든 것이 몇 달 안에 생태계 표준이 되는 흐름)이 에이전트 쪽에서 반복될 것으로 보인다. 다만 "AAIF 가입이 필수가 아니다"라는 설명과 별개로, 실제 의사결정 영향력은 결국 리드 메인테이너를 배출하는 회사들에 쏠릴 가능성이 있어, 거버넌스가 이름만큼 중립적으로 작동하는지는 지켜볼 지점으로 보인다.
