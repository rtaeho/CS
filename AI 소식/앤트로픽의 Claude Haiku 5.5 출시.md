앤트로픽이 "지금까지 내놓은 소형 모델 중 가장 저렴하고 빠르며 성능이 좋다"고 밝힌 Claude Haiku 5.5를 출시했다.
기준 시점: 2026-10-07

## 무슨 일인가

앤트로픽 공식 발표에 따르면 2026년 10월 7일 Claude Haiku 5.5(모델 ID `claude-haiku-5-5`)를 출시했다. 요약·[[컨텍스트 압축]]·DB 조회·분류처럼 비용에 민감한 대량 작업과, 코딩 작업에서 Opus 5.5·Sonnet 5.5와 함께 쓰이는 서브에이전트 역할을 겨냥한 모델이라고 소개한다.

가격은 100만 토큰당 입력 $0.10/$0.50(프롬프트 길이 10만 토큰 기준 이하/이상), 출력 $0.50/$2.50, 캐시 읽기 $0.01/$0.05, 캐시 쓰기 $0.125/$0.625다. 앤트로픽은 Haiku 4.5 대비 평균 약 75% 저렴해졌다고 밝혔고, 각주에서는 10만 토큰 이하 요청은 90% 더 저렴하고 10만 토큰을 넘는 요청은 50% 더 저렴하다고 구체적으로 밝혔다. 속도는 표준 속도 기준으로 지금까지 나온 모델 중 가장 빠르다고 설명하면서도, Opus 모델의 Fast Mode보다는 느리다고 함께 밝혔다.

벤치마크 결과도 여러 개 공개했다(Haiku 5.5 / Haiku 4.5 / Sonnet 5.5 순): OSWorld 2.1(오프라인 서브셋) 72.4% / 15.7% / 83.9%, Humanity's Last Exam(툴 사용) 57.4% / 18.7% / 64.5%, Terminal-Bench 4.0 39.2% / 0.0% / 70.6%. 앤트로픽은 복잡한 에이전틱 코딩 작업에는 여전히 Sonnet 5.5·Opus 5.5가 더 나은 선택이라고 밝혔다.

새로 들어간 기능으로는 **Effort 설정**(Low·Med·High·Xhigh·Max 중 추론 강도를 고를 수 있는 옵션)을 Haiku 계열 모델에 처음 적용했다고 밝혔고, Python·TypeScript SDK에 컴퓨터 사용·브라우저 사용 기능을 베타로 추가했다고 밝혔다. 안전 측면에서는 정렬 평가에서 Haiku 4.5보다 개선됐다고 밝혔고, 사이버보안 안전장치는 Haiku 4.5보다 엄격하지만 다른 최신 모델들보다는 느슨하다고 설명했다.

## 왜 중요한가

가장 저렴한 모델 등급에도 Effort 설정이 들어왔다는 점이 눈에 띈다. 지금까지 "비용 대 성능"을 맞추는 수단이 주로 "쉬운 작업은 더 작은 모델로 보낸다"(모델 라우팅)였다면, 이제는 같은 모델 안에서도 요청마다 추론 강도를 조절하는 방식이 저가 모델에까지 내려왔다는 뜻이다. 또한 컴퓨터·브라우저 사용 기능이 가장 저렴한 모델 등급에도 베타로 들어왔다는 점은, GUI를 직접 조작하는 에이전트를 돌리는 비용 장벽이 낮아지고 있다는 신호로 볼 수 있다.

## 짚고 갈 개념

- Effort 설정 — 모델을 호출할 때마다 추론 강도(Low~Max)를 선택해 비용과 성능을 맞바꾸는 옵션
- [[컴퓨터 사용]] — 에이전트가 화면을 보고 클릭·타이핑 같은 액션을 내보내 GUI를 직접 조작하는 툴 방식

## 내 생각

벤치마크 격차(OSWorld 72.4% vs Sonnet 5.5의 83.9%, Terminal-Bench 39.2% vs 70.6%)가 여전히 커서, Haiku 5.5가 단독으로 복잡한 에이전틱 작업을 떠맡기보다는 발표에서 강조한 대로 "더 큰 모델의 서브에이전트"로 쓰이는 쪽이 자연스러워 보인다. Effort 설정이 소형 모델까지 내려온 흐름은, 앞으로 모델 선택 자체보다 "같은 모델을 얼마나 생각시킬지"를 요청 단위로 조절하는 쪽이 비용 설계의 기본값이 될 수 있다는 방향으로 보인다.
