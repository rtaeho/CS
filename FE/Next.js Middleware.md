[[Next.js]]에서 요청이 라우트 핸들러나 페이지에 도달하기 전에 서버 사이드에서 실행되는 코드로, 인증·리다이렉션·헤더 수정 등을 처리합니다.

## 핵심 특징

- 프로젝트 루트나 `src` 디렉토리의 `middleware.ts` 파일로 정의
- 요청이 완료되기 전, 라우트 매칭 이전 시점에 실행
- Edge Runtime에서 실행되어 매우 빠른 응답 속도 제공

## 사용 예

- 인증 및 권한 검사
- 로그인하지 않은 사용자의 리다이렉션 처리
- 요청/응답 헤더 수정

## Edge Runtime

서버리스 환경에서 실행되는 경량 JavaScript 런타임으로, CDN의 엣지 노드에서 코드를 실행해 사용자와 가장 가까운 위치에서 응답합니다. 전 세계에 분산된 엣지 서버에서 실행되기 때문에 콜드 스타트가 거의 없고 응답 시간이 매우 빠릅니다.

이런 특성 때문에 `fs`나 워커 스레드 같은 Node.js API는 사용할 수 없고, `fetch`, `URL`, `URLSearchParams` 같은 웹 표준 API만 사용할 수 있습니다.

## 핵심 정리

Middleware는 Edge Runtime의 제약(Node.js API 사용 불가) 안에서 동작하는 대신, 빠른 응답 속도로 인증·리다이렉션 같은 요청 전처리 로직을 서버단에서 효율적으로 처리할 수 있게 해줍니다.
