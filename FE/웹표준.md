웹 기술들이 브라우저나 기기와 상관없이 일관되게 동작하도록 보장하기 위해 IETF, W3C 등 국제 표준 기구가 정의하고 관리하는 규약들의 집합입니다.

## 다루는 영역

웹표준은 HTML, CSS, JavaScript 같은 핵심 기술뿐 아니라 접근성, 통신, 보안 등 여러 영역까지 포괄합니다.

|영역|표준의 예|
|---|---|
|마크업|HTML5, [[시맨틱 마크업]]|
|스타일|CSS3|
|스크립트|ECMAScript(ES6+)|
|접근성|WCAG ([[웹 접근성]])|
|통신|HTTP/1.1, HTTP/2|

## 목적

```
[웹표준이 없는 경우]
브라우저 A: 특정 CSS 속성만 지원 → 레이아웃이 깨짐
브라우저 B: 다른 JS 문법으로 동작 → 별도 코드 분기 필요
→ 브라우저별로 각기 다른 버전을 만들어야 함

[웹표준을 따르는 경우]
모든 브라우저가 동일한 HTML/CSS/JS 명세를 구현
→ 한 번의 개발로 여러 브라우저·기기에 동일하게 서비스 제공
```

- **개발자 관점**: 특정 브라우저에 종속되지 않는 코드를 작성할 수 있어, 브라우저별 분기 처리 없이 한 번의 개발로 여러 환경을 지원할 수 있습니다.
- **사용자 관점**: 어떤 브라우저나 기기를 사용하더라도 콘텐츠가 일관되게 표현되어 더 나은 접근성과 사용자 경험을 얻을 수 있습니다.

예를 들어 HTML의 [[시맨틱 마크업|시맨틱 태그]]는 콘텐츠의 의미와 구조를 명확히 표현하고, CSS의 표준 속성은 스타일의 일관성을 보장하며, JavaScript는 ECMAScript 표준에 따라 구현되어 브라우저 간 동작이 일관됩니다.

## 지키지 않을 때 발생하는 문제

- 일부 브라우저에서 웹사이트가 의도한 대로 동작하지 않거나 레이아웃이 깨질 수 있습니다.
- 특정 기능이 브라우저에서 비활성화되거나 보안 취약점으로 이어질 수 있습니다.
- 기기 종류가 다양한 모바일 환경에서는 사용자 경험이 크게 저하될 수 있습니다.

## 핵심 정리

웹표준은 브라우저·기기와 무관하게 웹이 동일하게 동작하도록 보장하는 규약들의 집합으로, [[시맨틱 마크업]]과 [[웹 접근성]]을 지키는 것이 실무에서 웹표준을 준수하는 대표적인 방법입니다.
