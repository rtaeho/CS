IP 주소 할당 방식은 호스트에게 네트워크에서 사용할 IP 주소를 수동으로 지정하는 정적 할당과 DHCP로 자동 임대하는 동적 할당으로 나눌 수 있습니다.

## 정적 할당

정적 할당은 관리자가 IP 주소, 서브넷 마스크, 게이트웨이, DNS 주소를 직접 설정하는 방식입니다.

서버나 네트워크 장비처럼 주소가 자주 바뀌면 안 되는 대상에 적합합니다. 하지만 호스트가 많아지면 관리가 번거롭고 중복 IP 같은 실수가 생길 수 있습니다.

## 동적 할당

동적 할당은 [[DHCP]] 서버가 사용 가능한 IP 주소를 자동으로 임대하는 방식입니다. 일반 PC, 모바일 기기처럼 네트워크에 자주 들어오고 나가는 호스트에 적합합니다.

## 비교

| 항목 | 정적 할당 | 동적 할당 |
|---|---|---|
| 설정 방식 | 수동 | 자동 |
| 관리 비용 | 높음 | 낮음 |
| 주소 변경 | 거의 없음 | 변경 가능 |
| 중복 IP 위험 | 수동 실수 가능 | DHCP 서버가 관리 |
| 적합 대상 | 서버, 라우터, 프린터 | PC, 모바일, 임시 장비 |

## 핵심 정리

정적 IP는 주소가 고정되어야 하는 서버나 장비에 적합하고, 동적 IP는 많은 클라이언트의 IP를 자동 관리하는 데 적합합니다.
