음수 간선이 있는 그래프에서도 단일 시작점 최단 거리를 구할 수 있고, 음수 사이클의 존재까지 판별하는 알고리즘입니다.

## 동작 과정

모든 간선을 V−1번 반복해서 훑으며 거리를 갱신(relaxation)합니다.

```
[ 그래프 ] 음수 간선 포함
1 --(4)--> 2 --(-3)--> 3
|                      ^
+--------(5)-----------+

간선 목록: (1→2, 4), (2→3, -3), (1→3, 5)
시작=1, dist = [0, INF, INF]

── 1라운드 ──
(1→2, 4):  0+4=4  < INF → dist[2]=4
(2→3, -3): 4-3=1  < INF → dist[3]=1
(1→3, 5):  0+5=5  > 1   → 갱신 없음
dist = [0, 4, 1]

── 2라운드 ── (V-1 = 2라운드까지)
(1→2, 4):  0+4=4  = 4   → 갱신 없음
(2→3, -3): 4-3=1  = 1   → 갱신 없음
(1→3, 5):  0+5=5  > 1   → 갱신 없음
dist = [0, 4, 1]   ← 변화 없음, 확정

── V번째 라운드 (음수 사이클 검사) ──
갱신이 한 번이라도 일어나면 → 음수 사이클 존재
여기서는 갱신 없음 → 정상
```

최단 경로는 간선을 최대 V−1개 지나므로, V−1라운드면 모든 최단 거리가 확정됩니다. 그 뒤에도 갱신이 일어난다면 거리를 무한히 줄이는 음수 사이클이 있다는 뜻입니다.

## 구현

```java
// edges: int[]{from, to, weight}
// 반환: 최단 거리 배열, 음수 사이클이 있으면 null
long[] bellmanFord(int n, int start, List<int[]> edges) {
    long[] dist = new long[n];
    Arrays.fill(dist, Long.MAX_VALUE);
    dist[start] = 0;

    // V-1 라운드
    for (int round = 0; round < n - 1; round++) {
        boolean updated = false;
        for (int[] e : edges) {
            int from = e[0], to = e[1], weight = e[2];
            if (dist[from] == Long.MAX_VALUE) continue;  // 도달 불가 노드는 건너뜀
            if (dist[from] + weight < dist[to]) {
                dist[to] = dist[from] + weight;
                updated = true;
            }
        }
        if (!updated) break;  // 더 갱신될 게 없으면 조기 종료
    }

    // V번째 라운드에서 갱신되면 음수 사이클
    for (int[] e : edges) {
        int from = e[0], to = e[1], weight = e[2];
        if (dist[from] == Long.MAX_VALUE) continue;
        if (dist[from] + weight < dist[to]) return null;
    }
    return dist;
}
```

## 복잡도

| 구분 | 복잡도 | 근거 |
|---|---|---|
| 시간 | O(VE) | V−1라운드 × 매 라운드마다 간선 E개 전부 확인 |
| 공간 | O(V) | 거리 배열 (간선 목록은 입력) |

[[다익스트라]]의 O(E log V)보다 느리므로, **음수 간선이 없다면 다익스트라를 쓰는 게 맞습니다.**

## 주의사항

- **도달 불가 노드 건너뛰기**: `dist[from]`이 INF인 간선을 갱신에 쓰면 `INF + 음수`가 INF보다 작아져 엉뚱한 값이 퍼진다. 위 구현의 `continue` 가드가 이걸 막는다
- **오버플로**: 누적 합이 int 범위를 넘기기 쉬워 `long`을 쓰는 편이 안전하다
- **음수 사이클의 범위**: V번째 라운드에서 갱신된다는 건 "어딘가에 음수 사이클이 있다"는 뜻이고, 그게 시작점에서 도달 가능한 사이클인지는 별도로 확인해야 한다
- **최단 거리가 아예 정의되지 않는 경우**: 음수 사이클이 경로상에 있으면 최단 거리는 −∞라서 값을 반환하는 것 자체가 의미 없다 — 위 구현처럼 `null`로 구분한다

## 핵심 정리

- **음수 간선을 허용**하는 단일 시작점 최단 경로
- 모든 간선을 V−1번 훑는 방식 → O(VE)
- V번째 라운드에서 갱신되면 **음수 사이클 존재**
- 음수 간선이 없으면 [[다익스트라]], 모든 쌍이 필요하면 [[플로이드-워셜]]
