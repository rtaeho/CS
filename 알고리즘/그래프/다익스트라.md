간선 가중치가 모두 음수가 아닌 그래프에서 한 시작점으로부터 모든 노드까지의 최단 거리를 구하는 알고리즘입니다.

## 동작 과정

```
[ 그래프 ] (괄호는 가중치)
      (4)
   1 ————— 2
   |     / |
(1)|  (2)/ |(5)
   |   /   |
   3 ————— 4
      (8)

인접 리스트:
1: [(2,4), (3,1)]
2: [(1,4), (3,2), (4,5)]
3: [(1,1), (2,2), (4,8)]
4: [(2,5), (3,8)]

시작=1, dist 초기값 = [0, INF, INF, INF]

우선순위 큐(거리 오름차순)에서 하나씩 꺼내 확정:

PQ=[(0,1)]
  (0,1) 꺼냄 → 1 확정, dist[1]=0
    2: 0+4=4 < INF → dist[2]=4, PQ에 (4,2)
    3: 0+1=1 < INF → dist[3]=1, PQ에 (1,3)
PQ=[(1,3), (4,2)]
  (1,3) 꺼냄 → 3 확정, dist[3]=1
    2: 1+2=3 < 4  → dist[2]=3, PQ에 (3,2)   ← 더 짧은 경로 발견
    4: 1+8=9 < INF → dist[4]=9, PQ에 (9,4)
PQ=[(3,2), (4,2), (9,4)]
  (3,2) 꺼냄 → 2 확정, dist[2]=3
    4: 3+5=8 < 9 → dist[4]=8, PQ에 (8,4)
PQ=[(4,2), (8,4), (9,4)]
  (4,2) 꺼냄 → dist[2]=3 < 4 이므로 무시 (이미 확정)
  (8,4) 꺼냄 → 4 확정, dist[4]=8
  (9,4) 꺼냄 → dist[4]=8 < 9 이므로 무시

최종 dist = [0, 3, 1, 8]
```

한 번 큐에서 꺼내 확정된 노드의 거리는 다시 줄어들지 않습니다. 음수 간선이 없다면 "지금까지 가장 가까운 노드"가 곧 최단 거리라는 그리디 성질이 성립하기 때문입니다.

## 구현

```java
int[] dijkstra(int start, List<List<int[]>> graph) {  // int[]{다음 노드, 가중치}
    int n = graph.size();
    int[] dist = new int[n];
    Arrays.fill(dist, Integer.MAX_VALUE);
    dist[start] = 0;

    // {거리, 노드} — 거리 오름차순 최소 힙
    PriorityQueue<int[]> pq = new PriorityQueue<>((a, b) -> a[0] - b[0]);
    pq.offer(new int[]{0, start});

    while (!pq.isEmpty()) {
        int[] cur = pq.poll();
        int d = cur[0], node = cur[1];

        if (d > dist[node]) continue;  // 이미 더 짧은 경로로 확정된 노드

        for (int[] edge : graph.get(node)) {
            int next = edge[0], weight = edge[1];
            if (dist[node] + weight < dist[next]) {
                dist[next] = dist[node] + weight;
                pq.offer(new int[]{dist[next], next});
            }
        }
    }
    return dist;
}
```

[[PriorityQueue]]는 내부적으로 [[Heap]]으로 구현되어 있어 최소 거리 노드를 O(log V)에 꺼낼 수 있습니다.

## 복잡도

| 구현 방식 | 시간 | 근거 |
|---|---|---|
| 우선순위 큐 | O(E log V) | 간선마다 최대 한 번 큐에 삽입(O(log V)), 총 E번 |
| 인접 행렬 + 선형 탐색 | O(V²) | 매 단계 최소 거리 노드를 V개 중에서 선형 탐색 |

간선이 적은 희소 그래프는 우선순위 큐 방식이, V²에 가까운 밀집 그래프는 선형 탐색 방식이 유리합니다. 공간복잡도는 O(V + E).

## 주의사항

- **음수 간선 불가**: 음수 간선이 있으면 확정된 거리가 나중에 더 줄어들 수 있어 그리디 성질이 깨진다. 이 경우 [[벨만-포드]]를 써야 한다
- **중복 삽입 처리**: 같은 노드가 서로 다른 거리로 큐에 여러 번 들어간다. `if (d > dist[node]) continue;` 가드를 빼면 불필요한 탐색이 폭증한다
- **오버플로**: `Integer.MAX_VALUE`로 초기화한 뒤 `dist[node] + weight`를 계산하면 오버플로가 난다. 위 구현처럼 갱신 전에 비교하거나, 초기값을 충분히 큰 상수(예: 1e9)로 둔다
- **가중치가 모두 같다면** 다익스트라가 아니라 [[BFS]]로 충분하다 — O(V + E)로 더 빠르다

## 핵심 정리

- 음수 간선이 없는 그래프의 **단일 시작점 최단 경로**
- 매 단계 가장 가까운 미확정 노드를 확정하는 그리디 방식
- [[PriorityQueue]] 사용 시 O(E log V)
- 음수 간선이 있으면 [[벨만-포드]], 모든 쌍이 필요하면 [[플로이드-워셜]]
