원소들을 서로소 집합으로 묶고, 두 원소가 같은 집합에 속하는지를 거의 상수 시간에 판별하는 자료구조이자 알고리즘입니다.

## 동작 과정

각 집합을 트리로 표현하고 루트를 집합의 대표로 씁니다. 연산은 `find`(대표 찾기)와 `union`(두 집합 합치기) 둘입니다.

```
원소 1~6, 초기에는 각자가 자기 집합의 루트
parent = [1, 2, 3, 4, 5, 6]

union(1, 2) → find(1)=1, find(2)=2, 루트가 다르므로 합침
parent = [1, 1, 3, 4, 5, 6]
  1
  └ 2

union(3, 4)
parent = [1, 1, 3, 3, 5, 6]
  1      3
  └ 2    └ 4

union(2, 4) → find(2)=1, find(4)=3 → 1 아래에 3을 붙임
parent = [1, 1, 1, 3, 5, 6]
  1
  ├ 2
  └ 3
    └ 4

find(4) 경로 압축 전:  4 → 3 → 1   (2단계)
find(4) 경로 압축 후:  parent[4] = 1
  1
  ├ 2
  ├ 3
  └ 4                              (1단계)

isSameSet(2, 4) → find(2)=1, find(4)=1 → true
isSameSet(2, 5) → find(2)=1, find(5)=5 → false
```

경로 압축은 `find` 한 번으로 그 경로상의 모든 노드를 루트에 직접 매달아, 다음 조회를 평탄하게 만듭니다.

## 구현

```java
class UnionFind {
    private final int[] parent;
    private final int[] size;   // union by size

    UnionFind(int n) {
        parent = new int[n];
        size = new int[n];
        for (int i = 0; i < n; i++) {
            parent[i] = i;
            size[i] = 1;
        }
    }

    // 경로 압축
    int find(int x) {
        if (parent[x] == x) return x;
        return parent[x] = find(parent[x]);
    }

    // 작은 트리를 큰 트리에 붙여 깊이를 억제
    boolean union(int a, int b) {
        int rootA = find(a), rootB = find(b);
        if (rootA == rootB) return false;  // 이미 같은 집합 — 사이클

        if (size[rootA] < size[rootB]) {
            int tmp = rootA; rootA = rootB; rootB = tmp;
        }
        parent[rootB] = rootA;
        size[rootA] += size[rootB];
        return true;
    }

    boolean isSameSet(int a, int b) {
        return find(a) == find(b);
    }
}
```

`union`이 `false`를 반환하는 경우가 **사이클 판별**에 그대로 쓰입니다 — 간선을 추가하려는 두 노드가 이미 같은 집합이면 그 간선은 사이클을 만듭니다. [[크루스칼]]이 이 성질을 사용합니다.

## 복잡도

| 구분 | 복잡도 | 근거 |
|---|---|---|
| find / union | 거의 O(1) — 정확히는 O(α(N)) | 경로 압축 + union by size를 함께 쓰면 역아커만 함수 α(N), 실용 범위에서 4 이하 |
| 공간 | O(N) | parent 배열 + size 배열 |

최적화를 하나도 안 하면 한 줄로 늘어진 트리에서 `find`가 O(N)까지 떨어집니다.

## 주의사항

- **경로 압축 빼먹기**: `return find(parent[x])`로만 쓰면 압축이 안 된다. `parent[x] = find(parent[x])`로 대입까지 해야 한다
- **루트끼리 합치기**: `parent[b] = a`처럼 원소를 직접 연결하면 안 된다. 반드시 `find`로 루트를 구해 **루트끼리** 연결한다
- **재귀 깊이**: 압축 전 트리가 깊으면 재귀 `find`가 스택을 깊게 쓴다. 노드가 매우 많으면 반복문 버전으로 바꾼다
- **union by size vs rank**: 둘 다 목적은 트리 깊이 억제로, 성능 차이는 거의 없다. size는 "집합 크기"를 함께 알 수 있어 실전에서 더 쓸모가 많다

## 핵심 정리

- 서로소 집합을 관리하는 자료구조 — `find`(대표 찾기), `union`(합치기)
- **경로 압축 + union by size**를 함께 써야 거의 O(1)
- `union`이 실패하면 사이클 — [[크루스칼]]의 핵심 부품
- 연결 요소 개수 세기, 그룹 묶기, 사이클 판별에 쓰인다
