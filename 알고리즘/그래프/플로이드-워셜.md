모든 노드 쌍 사이의 최단 거리를 한 번에 구하는 동적 계획법 기반 알고리즘입니다.

## 동작 과정

"노드 k를 경유지로 써도 되는가"를 k=1..V까지 차례로 허용해가며 거리를 갱신합니다.

```
[ 그래프 ] (방향, 괄호는 가중치)
1 --(4)--> 2 --(1)--> 3
^                     |
+--------(2)----------+

초기 dist (INF = 도달 불가, 자기 자신은 0)
      1    2    3
 1 [  0    4   INF ]
 2 [ INF   0    1  ]
 3 [  2   INF   0  ]

── k=1 경유 허용 ──
2→1→3 : INF + ... → 2→1이 INF라 갱신 없음
3→1→2 : 2 + 4 = 6 < INF → dist[3][2] = 6
      1    2    3
 1 [  0    4   INF ]
 2 [ INF   0    1  ]
 3 [  2    6    0  ]

── k=2 경유 허용 ──
1→2→3 : 4 + 1 = 5 < INF → dist[1][3] = 5
3→2→1 : 6 + INF → 갱신 없음
      1    2    3
 1 [  0    4    5  ]
 2 [ INF   0    1  ]
 3 [  2    6    0  ]

── k=3 경유 허용 ──
2→3→1 : 1 + 2 = 3 < INF → dist[2][1] = 3
2→3→2 : 1 + 6 = 7 > 0   → 갱신 없음
      1    2    3
 1 [  0    4    5  ]
 2 [  3    0    1  ]
 3 [  2    6    0  ]

최종: 모든 쌍 최단 거리 완성
```

점화식은 `dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j])` 한 줄입니다.

## 구현

```java
// graph[i][j] = i→j 간선 가중치, 없으면 INF, graph[i][i] = 0
void floydWarshall(int[][] dist, int n) {
    final int INF = 1_000_000_000;

    for (int k = 0; k < n; k++) {          // 경유지
        for (int i = 0; i < n; i++) {      // 출발
            if (dist[i][k] == INF) continue;   // 가지치기
            for (int j = 0; j < n; j++) {  // 도착
                if (dist[k][j] == INF) continue;
                if (dist[i][k] + dist[k][j] < dist[i][j]) {
                    dist[i][j] = dist[i][k] + dist[k][j];
                }
            }
        }
    }
}
```

**반복문 순서에서 `k`가 가장 바깥이어야 합니다.** k가 안쪽으로 들어가면 "경유지를 1..k까지 허용했을 때의 최적해"라는 DP 단계 구분이 깨져 틀린 답이 나옵니다.

## 복잡도

| 구분 | 복잡도 | 근거 |
|---|---|---|
| 시간 | O(V³) | 경유지 V × 출발 V × 도착 V 삼중 반복 |
| 공간 | O(V²) | 인접 행렬 |

V가 400~500 정도까지가 현실적인 한계입니다. 그보다 크면 노드마다 [[다익스트라]]를 V번 돌리는 O(VE log V)가 더 빠를 수 있습니다.

## 주의사항

- **k 반복문이 최외곽**: 가장 흔한 실수. 순서를 바꾸면 조용히 틀린 답이 나온다
- **INF 덧셈 오버플로**: `INF + INF`가 int를 넘기지 않도록 INF를 `1e9` 수준으로 두거나, 위 구현처럼 INF인 경로를 `continue`로 걸러낸다
- **자기 자신 거리 초기화**: `dist[i][i] = 0`을 빼먹으면 모든 결과가 어긋난다
- **음수 사이클 판별**: 알고리즘 종료 후 `dist[i][i] < 0`인 i가 있으면 음수 사이클이 존재한다
- **도달 가능성 판별 용도**: 가중치를 0/1로 두면 "i에서 j로 갈 수 있는가"를 구하는 전이 폐쇄(transitive closure)로도 쓸 수 있다

## 핵심 정리

- **모든 쌍** 최단 거리를 O(V³)에 구한다
- 점화식 `dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j])`, **k 반복문이 최외곽**
- 음수 간선 허용, `dist[i][i] < 0`으로 음수 사이클 판별
- 단일 시작점이면 [[다익스트라]]나 [[벨만-포드]]가 훨씬 빠르다
