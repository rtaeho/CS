사이클이 없는 방향 그래프(DAG)에서 모든 간선의 방향을 거스르지 않도록 노드를 일렬로 나열하는 알고리즘입니다.

## 동작 과정

진입 차수(들어오는 간선 수)가 0인 노드부터 꺼내고, 그 노드가 가리키던 노드들의 진입 차수를 1씩 줄이는 방식입니다.

```
[ 선수 과목 그래프 ]
1 → 2 → 4
↓       ↑
3 ——————+

진입 차수: 1:0, 2:1, 3:1, 4:2

큐=[1]                        결과=[]
  1 꺼냄 → 2: 1→0 (큐 추가), 3: 1→0 (큐 추가)
큐=[2, 3]                     결과=[1]
  2 꺼냄 → 4: 2→1
큐=[3]                        결과=[1, 2]
  3 꺼냄 → 4: 1→0 (큐 추가)
큐=[4]                        결과=[1, 2, 3]
  4 꺼냄 → 나가는 간선 없음
큐=[]                         결과=[1, 2, 3, 4]

결과 길이 4 = 노드 수 4 → 사이클 없음, 유효한 위상 순서
```

진입 차수가 0이라는 건 "먼저 와야 하는 것이 모두 처리됐다"는 뜻입니다. 큐에 동시에 여러 개가 들어 있으면 그들 사이 순서는 자유로우므로, **위상 순서는 여러 개 존재할 수 있습니다.**

## 구현

```java
// 반환: 위상 순서, 사이클이 있으면 null
List<Integer> topologicalSort(int n, List<List<Integer>> graph) {
    int[] inDegree = new int[n];
    for (int node = 0; node < n; node++) {
        for (int next : graph.get(node)) {
            inDegree[next]++;
        }
    }

    Queue<Integer> queue = new ArrayDeque<>();
    for (int node = 0; node < n; node++) {
        if (inDegree[node] == 0) queue.offer(node);
    }

    List<Integer> result = new ArrayList<>();
    while (!queue.isEmpty()) {
        int node = queue.poll();
        result.add(node);

        for (int next : graph.get(node)) {
            if (--inDegree[next] == 0) {
                queue.offer(next);
            }
        }
    }

    // 전부 담기지 않았다면 사이클이 있어 진입 차수가 0이 되지 못한 노드가 남은 것
    return result.size() == n ? result : null;
}
```

[[BFS]]와 같은 큐 기반 구조이고, [[DFS]]로 구현해 **역순 후위 순회**를 뒤집는 방법도 있습니다.

## 복잡도

| 구분 | 복잡도 | 근거 |
|---|---|---|
| 시간 | O(V + E) | 진입 차수 계산에 E, 각 노드를 한 번씩 큐에 넣고 꺼내며 인접 간선을 한 번씩 확인 |
| 공간 | O(V) | 진입 차수 배열 + 큐 + 결과 리스트 |

## 주의사항

- **DAG만 가능**: 사이클이 있으면 위상 순서가 존재하지 않는다. 결과 개수가 V보다 적은지로 **사이클 판별**에 그대로 활용할 수 있다
- **진입 차수 감소 시점**: `--inDegree[next] == 0`일 때만 큐에 넣어야 한다. 0이 아닐 때 넣으면 선행 조건이 남은 노드가 먼저 처리된다
- **답이 여러 개**: 특정 순서를 요구하는 문제(예: 번호가 작은 것 먼저)라면 [[Queue]] 대신 [[PriorityQueue]]를 써서 꺼내는 순서를 제어한다
- **무방향 그래프에는 의미 없음**: 방향이 있어야 선후 관계가 정의된다

## 핵심 정리

- DAG의 노드를 선후 관계를 지키며 일렬로 나열
- 진입 차수 0인 노드부터 꺼내고 인접 노드의 진입 차수를 감소 — O(V + E)
- 결과 개수 < V 이면 **사이클 존재**
- 순서를 제어해야 하면 큐를 우선순위 큐로 바꾼다
