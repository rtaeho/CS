네트워크에서 호스트에게 IP를 할당하는 방식은 크게 정적 할당과 동적 할당으로 나눌 수 있습니다. 정리하면 [[IP 주소 할당 방식]]의 차이는 수동으로 고정하느냐, [[DHCP]]를 통해 자동으로 임대하느냐입니다.

## 정적 할당

정적 할당은 관리자가 호스트에 IP 주소를 직접 설정하는 방식입니다. 보통 IP 주소, 서브넷 마스크, 게이트웨이, DNS 주소를 직접 입력합니다.

서버나 네트워크 장비처럼 주소가 고정되어야 하는 대상에 적합합니다. 하지만 호스트 수가 많아질수록 관리가 번거롭고, 중복 IP를 설정하는 실수가 생길 수 있습니다.

## 동적 할당

동적 할당은 DHCP 서버가 사용 가능한 IP 주소를 자동으로 임대하는 방식입니다. IP가 고정적이지 않고 임대 기간이나 네트워크 상황에 따라 바뀔 수 있습니다.

DHCP는 Discover, Offer, Request, Acknowledgment 단계로 IP를 할당합니다.

```text
Discover -> Offer -> Request -> Acknowledgment
```

## 비교

| 항목 | 정적 할당 | 동적 할당 |
|---|---|---|
| 설정 방식 | 수동 | 자동 |
| 주소 변경 | 거의 없음 | 변경 가능 |
| 관리 비용 | 호스트가 많으면 큼 | 낮음 |
| 사용 예 | 서버, 라우터, 프린터 | PC, 모바일 기기 |

## 정리

정적 IP는 주소가 고정되어야 하는 장비에 적합하고, 동적 IP는 많은 호스트를 자동으로 관리할 때 적합합니다. DHCP를 사용하면 IP 임대와 갱신을 자동화할 수 있습니다.
